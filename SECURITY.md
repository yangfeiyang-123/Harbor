# Security

Harbor is an early-stage SSH client. Use it only with accounts and servers you
are authorized to access. Keep macOS, OpenSSH, remote Python, and your
simulation services up to date.

Do not post passwords, SSH private keys, live hostnames/IPs, tokens, or terminal
recovery files in public issues. For a vulnerability, use GitHub's **Security →
Report a vulnerability** if available. Otherwise open an issue requesting a
private reporting channel without disclosing exploit details or private data.

The app stores workspace and recovery data on your Mac; these may contain
sensitive output. Remote sessions run under your SSH user. Harbor is not a
sandbox for untrusted shell commands or remote projects.
