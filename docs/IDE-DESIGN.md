# Harbor 0.14.0 文件与代码工作区

## 采用的设计

- **按服务器保存工作区状态**：服务器之间隔离目录、最近使用目录、打开文件和终端标签页。参考 [VS Code 工作区文档](https://code.visualstudio.com/docs/editing/workspaces/workspaces) 对目录、打开文件与界面状态的组织。每台服务器可保留多个独立目录工作区，各自保留文件、终端、分屏和选中项；相同根目录复用既有工作区。
- **原生框架负责桌面体验**：目录树、分隔条、文件标签页、设置和终端由 SwiftUI / AppKit 组成，PDF 用 PDFKit，视频用 AVPlayerView。参考 [CodeEdit](https://github.com/CodeEditApp/CodeEdit) 的原生 macOS 方向与模块化编辑器设计。[CodeEditSourceEditor](https://github.com/CodeEditApp/CodeEditSourceEditor) 提供原生 tree-sitter 编辑器，是后续原生编辑能力的参考。
- **内嵌 CodeMirror 6**：从 [CodeMirror 官方项目](https://github.com/codemirror/dev) 与 [basic-setup](https://github.com/codemirror/basic-setup) 学习独立嵌入。目录与 SSH 能力由 Harbor 提供；代码区使用小型模块化编辑器，集成行号、折叠、语法高亮、缩进、撤销、查找替换与自动换行。资源随应用离线打包，不依赖 CDN 或在线 IDE 服务。GitHub 开发仓库已迁至其 README 指向的维护站点。
- 也查阅了 [Monaco Editor](https://github.com/microsoft/monaco-editor) 的独立编辑器方案。当前需求以 SSH 文件阅读与轻量编辑为主，选择 CodeMirror 以简化打包与原生交互边界。
- Markdown 使用 [Marked](https://marked.js.org/) 与 [DOMPurify](https://github.com/cure53/DOMPurify)。正文保留表格、列表、代码、引用和链接；过滤可执行 HTML，并用内容安全策略禁止外部资源和网络请求。点击 http(s)/mailto 链接才交给系统浏览器。当前不自动加载 Markdown 的外部或相对路径图片。

## 工作方式

顶部“文件与代码”或 ⌥Z 开启文件工作区，⌥X 最大化或恢复底部终端。设置 → 快捷键可录制其他组合，立即生效；按 Esc 取消录制。工作目录按钮提供路径输入、本机选取器和最近目录，支持绝对路径或 `~`。目录树可展开、筛选已展开的文件、显示隐藏文件、新建文件/文件夹、复制路径和设为工作目录。右键目录或文件即可在对应位置打开终端；⌘T 默认使用当前工作目录。⌘J 收起或展开底部终端。目录树宽度和代码/终端高度可拖动调整。

终端模式的每个顶部标签代表一个独立工作区。⌘D / ⌘H 在组内进行左右/上下切分，保留同一个顶部标签；⌘T 创建新的独立工作区。每组保留布局、比例和上次选中格子，关闭原始格子或重连不会改变组身份。

文件模式的底部只呈现当前选中的一个终端，右侧纵向列表按分屏视觉顺序列出当前目录工作区的终端。单击列表切换会话，双击或右键重命名；可单独关闭会话。列表宽度可在 52–240 pt 范围内拖动调整，窄时保留图标和悬停名称，长列表可滚动。文件模式不重建 shell，也不改写分屏树；回到终端模式恢复原来的分屏。底部高度的最小值按单终端计算，隐藏的分屏行不会继续挤占代码区。

目录栏展开/收起使用 0.42 秒缓动，按实际呈现宽度逐帧布局原生编辑器和终端。四个操作按钮沿曲线从两排移动到一排，名称、缩进和搜索框连续过渡；拖动分隔条时取消隐式动画以紧跟指针。系统“减少动态效果”关闭宽度动画。

代码可编辑，⌘S 保存；⌘F 查找替换，Tab 缩进。支持 Python、JavaScript/TypeScript、JSON/notebook 源码、Markdown、C/C++、Rust、HTML/CSS、YAML、Shell、Swift、Go 的高亮；其他 UTF-8 文件可作为纯文本编辑。文件标签切换保留内容、选择位置和撤销状态。每个可见工作区最多常驻最近 3 个编辑器，离开工作区后释放其闲置 WebView；快照保留 CRLF、撤销记录及滚动位置。重启只按需载入选中文件，其余标签保留路径。修改后的标签显示圆点，关闭或退出前提示未保存内容。

设置分别控制界面字号（11–20 pt）、代码/Markdown 字号（9–32 pt）和终端字号（9–32 pt）。⌘= / ⌘− 调整当前编辑器或终端，⇧⌘0 恢复 13 pt。终端字号变化会重新计算行列，不需要断开连接；独立窗口同样生效。PDF 自带缩放按钮和适应窗口。

## 数据与传输

### 拖拽和紧凑布局

顶部目录名称旁的箭头只列出现有工作区；右侧独立加号添加目录，关闭入口在工作台选项里。单击服务器后，上下方向键按当前显示顺序选择服务器，不截获编辑器和 shell 的方向键。

Harbor 内部的拖拽项目携带服务器身份。文件夹拖入右侧编辑区打开独立目录工作区，同服务器文件拖入后加入当前文件标签，保留原工作目录和未保存修改。本机项目放进远程编辑区时在本机空间打开；放到远程目录树的目标文件夹才上传。目录树内拖动默认移动，按住 Option 拷贝；跨服务器传输保留源文件。目标文件夹高亮，并浮出半透明面板显示目的目录名称和路径。

文件或文件夹拖入终端只插入经过 shell 转义的路径与空格，不追加回车。接受本机文件 URL 和当前服务器的文件路径，拒绝其他服务器的路径及控制字符；终端的服务器认证完成后才接收路径拖放。服务器和终端排序使用独立的进程内拖放类型，蓝色插入标记在放下、取消或移出应用结束拖动时清除。

目录树右键菜单和列表焦点支持复制 ⌘C、复制路径 ⌘⌥C、重命名 Enter、删除 ⌘Delete；文件夹支持粘贴 ⌘V，下载没有快捷键。文件重命名或移动后同步更新打开文件、未保存草稿和目录状态。删除进入本机废纸篓或远端 `~/.local/share/Harbor/Trash/`，远端每项包含原路径记录；删除有未保存修改的项目会被阻止。

服务器侧栏与文件目录栏均可缩到 52 pt。名称随宽度连续淡出和收拢，采用平滑曲线计算文字空间、行高、间距和树缩进；菜单切换使用弹簧过渡。顶部可压到 30 pt，并横跨全窗口，为原生窗口按钮预留空间，侧栏分隔线不再穿过按钮。紧凑模式包含导航、服务器、本机、顶部操作、文件树、文件及终端标签。图标保留可访问名称，目录仍用小箭头表示展开状态，搜索和新增入口保持可用。分隔条支持鼠标拖动、双击恢复及辅助功能增减操作。

图标使用按含义设计的悬停动画，包括齿轮旋转、服务器灯光序列、网络节点、电脑开屏、芯片脉冲、文件夹展开、文档逐行出现、视频播放提示和音频波形。动态以主题蓝色和低饱和辅助色表现；只有悬停图标刷新动画，系统开启“减少动态效果”时改为静态高亮。名称提示延迟 350 ms，以不激活、不接收鼠标输入的小面板显示，不抢终端或编辑器焦点；移动离开、点击、输入或滚动后关闭。10 种服务器 SF Symbols 内置于代码目录，选择持久化到服务器配置的可选字段；旧配置加载后补齐，新增优先使用空闲或最少使用的图标，编辑服务器时可手动更换。

### 最近打开

启动页与侧栏提供最近 12 个服务器/目录入口，参考工作区启动页的项目名、服务器标识与路径组合。成功登录或浏览目录后更新最近使用时间，同一服务器和规范化路径只保留一个入口。点击入口恢复目录并切换已有终端，或在对应目录建立新终端；可用 tmux 标识一起保留。旧历史列表与命令输出记录已关闭，最近入口仅保存恢复工作位置所需的元数据。

### 文件读写

- 本机文件直接通过 Foundation 读取。远程文件通过已有的 SSH ControlMaster 通道按需读取，文件功能不悄悄建立备用连接。尚未认证时，引导用户打开终端后刷新。
- 服务器需要 Python 3，仅临时执行 Python 脚本，不安装后台服务。普通请求通过 stdin JSON 传输；上传时请求参数使用 Base64 JSON，stdin 专供二进制文件流。命令参数和目录终端使用单引号安全转义。
- 文件夹上传和下载使用有界分块流，每次读写不超过 1 MiB；传输先进入私有临时目录，完成后再发布，不静默覆盖已有项目。拷贝遇到重名自动使用 `copy` 后缀；移动或重命名遇到重名报告冲突。支持普通文件、目录和指向所传目录内部的相对符号链接，拒绝特殊设备和越界路径。此版本未测量新的全应用内存降幅。
- 文件 stdout 与诊断 stderr 分离，二进制不会经过文本转换或输出截断。缓存目录权限 700、远程缓存文件 600；关闭文件删除其缓存，正常退出清理工作区缓存。崩溃遗留的系统临时文件交由系统临时目录清理。
- 保存时比对原文件 SHA-256，文件已被其他程序修改则拒绝覆盖。采用同目录临时文件、权限保留、写入前复查和原子替换。符号链接指向的文件被更新，链接本身保留。不声称能锁住不合作的外部写入程序。
- 目录和打开文件路径保存在应用自己的 UserDefaults，按服务器 UUID 和目录工作区 UUID 区分；旧服务器空间兼容保留。文稿内容不写入配置；未保存改动不是自动保存草稿。

## 自动同步与资源管理

文件区可见且应用处于前台时，观察根目录、已展开目录和当前文件父目录。本机用目录事件合并 200 ms 加 2 秒兜底检查；远程每轮结束后间隔 2 秒，通过同一 SSH 请求最多批量检查 32 个目录。目录 inode 和修改时间未变时省去目录列表，只额外读取当前文件元信息。错误间隔逐步延长至 30 秒；切换目录、模式或退到后台取消监控和文件请求。展开状态与筛选保持，折叠目录缓存回收。

当前文件连续两次检查稳定后才自动重新读取，未保存内容保持不动，保存仍检查 SHA-256 冲突。播放器退出预览即释放，大幅面静态图按最长边 4096 像素解码为显示预览，GIF 沿用原生处理，原文件不变。

## 当前边界

这是集成文件浏览、代码编辑和终端的轻量工作区，不包含 VS Code 扩展市场、语言服务器、调试器或 Git 操作面板。Notebook 当前查看 JSON 源码。

代码/Markdown 编辑上限为 2 MB；其他预览单文件上限 512 MB。超过 25 MB 的文件需点击载入，远端视频下载到本机临时缓存后播放，不是实时流媒体。视频编码受 macOS 支持范围限制，H.264/AAC MP4 已验证。目录每次最多显示 10,000 项，文件筛选只针对已展开目录。

## 可复现构建

编辑器源码在 `Editor/editor.js`，精确依赖与完整性摘要在 `Editor/package-lock.json`。修改编辑器后运行：

```sh
npm --prefix Editor ci --ignore-scripts
npm --prefix Editor run build
```

应用构建直接使用已打包的 `Resources/Editor`，最终用户不需要 Node.js。组件完整许可证随包附在 `THIRD-PARTY-LICENSES.txt`；依赖审计于 2026-09-05 显示 0 个已知漏洞。
